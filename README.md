# AI Spend Audit

AI Spend Audit is a modern web application that helps startups and teams analyze AI tool expenses and discover optimization opportunities.

## Features

- AI Spend analysis
- Monthly and yearly savings estimation
- AI - generated optimization summary
- Risk level detection
- Confidence score system
- Multi - tool support
- Responsive modern UI

## Supported Tools

- ChatGPT
- Claude
- Cursor
- GitHub Copilot
- Gemini
- OpenAI API

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
